# Portfolio Cute Pastel

Portfolio responsif dengan palet Baby Blue, Lavender, Cream, dan Navy.

## Fitur
- Home, About (Profil → Pendidikan → Skill), Contact
- Navbar + dropdown pendidikan
- Animasi reveal dan floating
- 4 modul CSS: reset, variables, components, animations
- GitHub hanya sebagai tautan eksternal, bukan section

## Cara menjalankan
Buka `index.html` di browser.
